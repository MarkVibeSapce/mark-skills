# Ghost Chat Filter — เช็คแชทผีบนเพจคุณ

> เป้าหมาย: บอกเจ้าของเพจว่า "ข้อความที่ได้จากแอด เป็นลูกค้าจริงกี่ %"
> แล้วถ้าแชทผีเยอะ → บอกสาเหตุ + วิธีแก้ที่ทำเองได้

ทำงานกับ 3 ไฟล์ในโฟลเดอร์นี้:
- `ghost_filter.py` — ตัวดึงข้อมูล + คัดกรอง (รันจริง)
- `STANDARD.md` — มาตรฐานเต็ม (สาเหตุ 9 ข้อ + วิธีแก้ทั้งหมด) ใช้อ้างอิงตอนแนะนำ

---

## หลักคิด (พูดให้ผู้ใช้ฟังสั้นๆ ก่อนเริ่ม)

"แชทผี" = ข้อความที่ Facebook นับเป็น "คนสนใจ" ในหน้าแอด แต่ไม่ใช่ลูกค้าจริง —
กดปุ่มสำเร็จรูปมั่วๆ, กดผิดเพจ, หรือทักแล้วเงียบ

ทำให้เห็นตัวเลข **"ค่าต่อข้อความ" ถูก (ดูดี)** แต่จริงๆ **ไม่มีคนซื้อ** เพราะครึ่งนึงเป็นผี
→ ต้องดู **คุณภาพ** ไม่ใช่ **จำนวน**

---

## ขั้นตอน (พาผู้ใช้ทีละสเต็ป — ห้ามข้าม)

### สเต็ป 1 — เอา "เลขเพจ" (Page ID) + "รหัสเพจ" (Page Token)

ต้องได้ 2 อย่างจากเพจของผู้ใช้เอง ลองตามลำดับนี้:

**ทาง A — ถ้ามี Facebook / Meta MCP เชื่อมอยู่**
ถ้า session นี้มี MCP tool ของ Facebook/Meta (เช็คจาก tool ที่มี) → ใช้ดึง Page ID + Page Access Token ให้เลย ผู้ใช้ไม่ต้องทำเอง

**ทาง B — ผู้ใช้ทำเอง (ไม่มี MCP) — พาไปทีละคลิก (ลำดับสำคัญ ห้ามสลับ)**
1. เปิด **Graph API Explorer**: https://developers.facebook.com/tools/explorer/
2. กด **Add permissions** ใส่สิทธิ์ 2 ตัวก่อน: `pages_messaging`, `pages_read_engagement`
   แล้วกด **Generate Access Token** (จะเด้งให้ล็อกอิน/อนุญาต — กดยอมรับ)
3. **ตอนนี้** ช่อง **"User or Page"** (มุมขวาบน) ถึงจะมีเพจให้เลือก → เลือกชื่อเพจตัวเอง
   ระบบจะสลับเป็น **Page Access Token** ให้อัตโนมัติ — คัดลอกเก็บไว้
4. เอา **Page ID**: ในช่อง query พิมพ์ `me?fields=id,name` แล้วกด **Submit** →
   ค่า `id` ที่ได้ = เลขเพจ (Page ID)
   *(ถ้าเผลอวาง User token มาก็ได้ — สคริปต์แลกเป็น Page token ให้เอง)*

> บอกผู้ใช้ให้ **วางเลขเพจ + token มาในแชท** (token นี้เป็นของเพจตัวเอง หมดอายุใน ~1 ชม.
> ใช้เช็คครั้งเดียวแล้วทิ้งได้ ไม่ต้องเก็บ)

### สเต็ป 2 — รันตัวกรอง

```bash
cd <โฟลเดอร์ skill นี้>
PAGE_ID=<เลขเพจ> PAGE_TOKEN=<token> python3 ghost_filter.py
```

สคริปต์ต้องใช้แค่ Python 3 (ไม่ต้องลง library เพิ่ม) จะ print รายงาน +
บรรทัดสุดท้ายเป็น JSON — อ่าน JSON นั้นมาสรุปต่อ

### สเต็ป 3 — แปลผลให้ผู้ใช้ (ภาษาชาวบ้าน)

จาก JSON ที่ได้ (`ghost_pct`, `verdict`, `real`, `ghost`, `samples`) สรุปเป็น:

```
📊 เพจคุณใน 7 วันล่าสุด:
   ได้ข้อความ [total] แชท → ลูกค้าจริง [real] · แชทผี [ghost]

   {emoji} แชทผี [ghost_pct]% = [verdict]
```

เกณฑ์ (จาก STANDARD.md §7):
| แชทผี % | สถานะ | ความหมาย |
|---------|-------|----------|
| 🟢 < 20% | ปกติ | สบายใจได้ ดูแลต่อไป |
| 🟡 20–40% | เฝ้าระวัง | เริ่มมีปัญหา ควรปรับ |
| 🔴 > 50% | วิกฤต | เสียเงินแอดฟรีเยอะ ต้องแก้ด่วน |

### สเต็ป 4 — ถ้าแชทผีเยอะ (🟡/🔴) บอกสาเหตุ + วิธีแก้

อ่าน `STANDARD.md` แล้วเลือก **3 ข้อที่น่าจะใช่ที่สุด** มาแนะนำ ภาษาที่เจ้าของเพจทำเองได้
สาเหตุที่เจอบ่อยสุด (เรียงตามผลกระทบ):

1. **ปุ่มทักอัตโนมัติ (Ice Breaker)** ที่เป็นปุ่มกลางๆ เช่น "ฉันสนใจ" → คนกดมั่ว
   *แก้:* ปิดปุ่ม หรือเปลี่ยนเป็นคำถามคัดกรอง ("งบประมาณเท่าไหร่", "สนใจรุ่นไหน")
   ทำที่ **Business Suite → กล่องข้อความ → ระบบอัตโนมัติ** (ไม่ใช่ในหน้าแอด)
2. **เป้าหมายแอดเป็น "ข้อความ"** → Facebook หาคนชอบกดแชท (ถูกสุด) ไม่ใช่คนซื้อ
   *แก้:* ลองเปลี่ยนเป็นฟอร์มเก็บข้อมูล (มีคำถามคัดกรอง) หรือโทร
3. **ยิงกว้างเกิน / เปิด Audience Network** → ได้คนกดผิด
   *แก้:* ปิด Audience Network เหลือแค่ Facebook + Instagram, ปักหมุดพื้นที่ + รัศมี

> รายละเอียดครบทุกสาเหตุ + วิธีแก้ อยู่ใน `STANDARD.md` — ชี้ให้ผู้ใช้อ่านต่อได้
