# มาตรฐานจัดการแชทผี (Ghost Chat Standard)

> คู่มือฉบับเจ้าของธุรกิจ — สำหรับใครที่ยิงแอด "ข้อความ/แชท" แล้วได้ตัวเลขสวย
> แต่ไม่มีลูกค้าจริง อ่านจบเข้าใจทั้ง "ทำไมเกิด" และ "แก้ยังไง"

---

## 1. แชทผีคืออะไร

**แชทผี** = ข้อความที่ถูกนับเป็น "ผู้สนใจ" ในตัวเลขแอด แต่**ไม่มีความตั้งใจซื้อจริง** —
ไม่ตอบต่อ, ไม่ให้ข้อมูล, ไม่กลายเป็นลูกค้า

**อาการ:** ค่าต่อข้อความดูดี (เช่น 200–400 บาท) แต่ **ต้นทุนต่อลูกค้าจริงสูงมาก**
(5,000–8,000 บาท+) เพราะ 50–65% เป็นคนกดปุ่มมั่ว / ผิดเพจ / ไม่คุยต่อ

**ตัวเลขหลอกตา:**
```
ค่าต่อข้อความ (ที่แอดโชว์) = เงินที่ใช้ ÷ จำนวนข้อความทั้งหมด (รวมผี)
ต้นทุนต่อลูกค้าจริง        = เงินที่ใช้ ÷ จำนวนคนที่ตั้งใจซื้อจริง

ตัวอย่าง: ใช้ไป 22,650 ÷ 58 ข้อความ = 391 บาท/ข้อความ  (ดูดี)
แต่ลูกค้าจริงมีแค่ ~7 → 22,650 ÷ 7 = 3,236 บาท/ลูกค้าจริง  (แพงกว่า 8 เท่า)
```

> "จำนวนข้อความ" หลอกตา — ต้องดู **คุณภาพ** ไม่ใช่ปริมาณ

## 2. สาเหตุ — เรียงตามผลกระทบ (มาก → น้อย)

| # | สาเหตุ | ทำไมเกิดแชทผี | ใครคุมได้ |
|---|--------|--------------|-----------|
| 1 | **ปุ่มทักอัตโนมัติ (Ice Breaker)** | ปุ่มสำเร็จรูป ("ฉันสนใจ", "ขอคุยเจ้าหน้าที่", "นัดเวลาดู") คนกดโดยไม่คิด = นับเป็นข้อความทันทีแต่ไม่มีความตั้งใจ | **เรา** (ตั้งค่าเพจ) |
| 2 | **เป้าหมายแอด = ข้อความ/แชท** | Facebook หา "คนชอบกดแชท" (ถูกสุด) ไม่ใช่คนซื้อ → ยิ่งได้ผี | **เรา** (ตั้งค่าแอด) |
| 3 | **เปิด Audience Network** | ตำแหน่งโฆษณาคุณภาพต่ำ คนกดผิด/กดโดนโดยบังเอิญ | **เรา** |
| 4 | **เปิดขยายกลุ่มเป้าหมายอัตโนมัติ** | Facebook ขยายไปกลุ่มไม่ตรงเอง | **เรา** |
| 5 | **ยิงกว้างเกินไป** | ความสนใจกว้าง ≠ อยากซื้อ (เช่นเจาะ "แพทย์" ได้คนสนใจข่าวหมอ ไม่ใช่หมอ) | **เรา** |
| 6 | **สินค้าแพง/ตัดสินใจนาน แต่ยิงผ่านแชท** | ของราคาสูงคนไม่ปิดผ่านแชท — เห็นแอด→จำแบรนด์→ค้นหาเอง→โทร | ดูความเหมาะสมสินค้า |
| 7 | **ส่งข้อความหาลูกค้าเก่าเป็นกลุ่ม (Broadcast)** | เพจส่งหาลูกค้าเก่า นับเป็นการสนทนาแต่ไม่มีใครตอบ | ทีมเพจ |
| 8 | **สแปม / เอเจนต์ / ทักผิดเพจ** | คู่แข่ง/คนขายของทักมา | ธรรมชาติ (บล็อก/กรองคำ) |
| 9 | **คนเห็นแอดซ้ำเยอะ (เกิน 4–5 ครั้ง)** | เห็นบ่อยจนชิน กดมั่วโดยไม่คิด | **เรา** (เปลี่ยนรูป/กลุ่ม) |

**สรุป:** สาเหตุอันดับ 1–5 และ 9 = **เราแก้เองได้** ผ่านการตั้งค่าแอด/เพจ ไม่ใช่ความผิดของรูปโฆษณาหรือทีมขาย

> ⚠️ จุดสำคัญ: ปุ่มทักอัตโนมัติ (#1) แก้ที่ **Business Suite → กล่องข้อความ → ระบบอัตโนมัติ**
> ส่วนเป้าหมาย/ตำแหน่ง/กลุ่ม (#2–5) แก้ในตัวจัดการโฆษณา (Ads Manager) — **คนละที่กัน**

## 3. วิธีตรวจ (ทำเองได้)

### วิธีง่ายสุด — ใช้ตัวกรองในชุดนี้
รัน `ghost_filter.py` (ดู `SKILL.md`) จะดึงกล่องข้อความ 7 วันล่าสุดมาแยกให้ว่า
ทักจริงกี่ % แชทผีกี่ % อัตโนมัติ

### ตรวจด้วยตาเอง — ดู "ข้อความแรก" ของลูกค้า
1. เปิดกล่องข้อความเพจ ไล่ดูข้อความ **แรกสุด** ที่ลูกค้าแต่ละคนพิมพ์
2. ถ้าเจอข้อความ **เป๊ะๆ เหมือนกัน** ซ้ำหลายคน (เช่น "ฉันสนใจ", "🏡 รายละเอียดบ้าน")
   → นั่นคือ **ปุ่มสำเร็จรูป = แชทผี**
3. ถ้าเป็นคำถามที่แต่ละคนพิมพ์ไม่เหมือนกัน (ถามราคา/ขนาด/นัดดู) → **ทักจริง**

**อัตราคุณภาพ = คนพิมพ์เองจริง ÷ ทั้งหมด**

### สัญญาณเตือน (ถ้าเป็นคนดูตัวเลขแอดเอง)
- ค่าต่อข้อความถูก แต่ยอดขาย/นัดหมาย = 0
- คนบล็อกเพจเยอะผิดปกติ
- คนทักแล้วหายไม่พิมพ์ต่อเกินครึ่ง

## 4. วิธีแก้

| ปัญหา | วิธีแก้ |
|-------|--------|
| ปุ่มทักอัตโนมัติกลางๆ | **ปิด** หรือเปลี่ยนเป็น **คำถามคัดกรอง** (งบ / รุ่นที่สนใจ / เมื่อไหร่จะซื้อ) |
| เป้าหมายเป็นข้อความ | เปลี่ยนตามสินค้า → **ฟอร์มเก็บข้อมูล** (มีคำถามกรอง) / **โทร** / **ส่งไปหน้าเว็บ+โทร** |
| Audience Network | **ปิด** เหลือแค่ Facebook + Instagram (Feed + Reels + Story) |
| ขยายกลุ่มอัตโนมัติ | **ปิด** การขยายกลุ่มเป้าหมายอัตโนมัติ |
| ยิงกว้าง | เจาะกลุ่มให้แคบ + ใช้กลุ่มที่คล้ายลูกค้าเก่า (Lookalike 1%) |
| ส่งหาลูกค้าเก่าเป็นกลุ่ม | อย่านับรวมในรายงาน / อย่าส่งซ้ำ |
| สินค้าแพง | **ให้หลายช่องทาง:** โทร + ฟอร์ม + แชท ให้ลูกค้าเลือกที่ถนัด |
| คนกดมั่วซ้ำ | **ตัดกลุ่ม** คนที่เคยทักแต่ไม่คุยต่อออกจากการยิง |

### ข้อความต้อนรับแบบคัดกรอง (ถ้ายังต้องใช้แชท)
```
โชว์ราคา/เงื่อนไขตั้งแต่แรก → คนไม่จริงจะเด้งออกเอง
+ ปุ่มคำถามคัดกรอง 3 ปุ่ม (งบเท่าไหร่ / สนใจอะไร / เมื่อไหร่)
```
ต่างจากปุ่มเดิม: "ฉันสนใจ" (ใครก็กด) → เปลี่ยนเป็น "งบเท่าไหร่" (เผยคุณภาพทันที)

## 5. เช็กลิสต์ก่อนยิงแอดใหม่ทุกครั้ง

- [ ] เป้าหมายตรงกับสินค้า (แชทเฉพาะสินค้าตัดสินใจเร็ว/ราคาไม่สูง)
- [ ] ปุ่มทักอัตโนมัติ = คำถามคัดกรอง ไม่ใช่ปุ่มกลางๆ (หรือปิดไปเลย)
- [ ] **ปิด Audience Network** (เหลือ Facebook + Instagram)
- [ ] ปิดการขยายกลุ่มอัตโนมัติ
- [ ] ข้อความต้อนรับแบบคัดกรอง (โชว์ราคา/เงื่อนไข)
- [ ] ปักหมุดพื้นที่ + รัศมี (ไม่ยิงทั้งจังหวัด/ทั้งประเทศ)
- [ ] เจาะกลุ่มให้ตรง — ไม่กว้างเกิน
- [ ] เปลี่ยนรูปโฆษณาก่อนคนเห็นซ้ำเกิน 4–5 ครั้ง
- [ ] วัด **คุณภาพ** (คนคุยต่อ/ตั้งใจซื้อ) ไม่ใช่แค่ค่าต่อข้อความ

## 6. ตัวเลขที่ควรดู (แทนที่จะดูค่าต่อข้อความอย่างเดียว)

| ตัวเลข | เป้า |
|--------|------|
| ต้นทุนต่อการสนทนาคุณภาพ (คุยต่อ 2+ ครั้ง) | ตามแต่ละธุรกิจ |
| อัตราคนคุยต่อ | > 20% |
| อัตราลูกค้าตั้งใจซื้อ (พิมพ์เอง + ตรงเกณฑ์) | > 30% |
| ยอดจริง (นัด/ปิดการขาย) | ตามเป้าธุรกิจ |
| **% แชทผี** (ปุ่ม+สแปม+ส่งกลุ่ม) | < 20% |

> ⚠️ ค่าข้างบนเป็น **จุดเริ่มต้น** — สินค้าแพง/ตัดสินใจนาน อัตราคนคุยต่อจะต่ำกว่าธรรมชาติ ·
> สินค้าถูก/ซื้อง่ายจะสูงกว่า · ตั้งเป้าเทียบกับ "เดือนแรก" ของเพจตัวเองเป็นหลัก

## 7. เกณฑ์: แชทผียอมรับได้แค่ไหน

| % แชทผี | สถานะ | ทำอะไร |
|---------|-------|--------|
| 🟢 **< 20%** | ปกติ | ดูแลต่อไป |
| 🟡 **20–40%** | เฝ้าระวัง | ปรับกลุ่ม / ตำแหน่งโฆษณา / ปุ่มทักอัตโนมัติ |
| 🔴 **> 50%** | วิกฤต | รื้อใหม่: เปลี่ยนเป้าหมาย + ปิดปุ่มทักอัตโนมัติ + ให้หลายช่องทาง |

## 8. เคสตัวอย่างจริง (บ้านหรูริมทะเล)

- สินค้า: บ้านริมทะเลราคาสูง · ยิงแอดเป้าหมาย "ข้อความ" + เปิดปุ่มทักอัตโนมัติ
- **แชทผี 55%** · พิมพ์เองจริงแค่ 13% · คนคุยต่อแค่ 5% · นัดชมบ้าน 0
- 65% เปิดแชทด้วยการกดปุ่มสำเร็จรูป → **0% พิมพ์คำถามตามมา**
- **แก้:** ปิดปุ่มทักอัตโนมัติ + เพิ่มโทร + ฟอร์มคัดกรอง + ปิด Audience Network +
  ปิดขยายกลุ่มอัตโนมัติ + ใช้กลุ่มคล้ายลูกค้าเก่า + วัดคนคุยต่อแทนค่าต่อข้อความ
- ผล: จำนวนข้อความลดลง แต่คุณภาพพุ่ง (ได้เบอร์จริง + งบ + ทีมขายโทรได้)

### ตรวจลึกด้วย API (Ads Manager insights)
ดู funnel จาก `actions` + `cost_per_action_type`:
```
messaging_conversation_started_7d      (เริ่มแชท)
  → total_messaging_connection          (นับเป็น connection)
  → messaging_first_reply               (ตอบครั้งแรก)
  → messaging_user_depth_2_message_send (คุยลึก 2+)  ← ตัวชี้วัดหลัก
  + messaging_block                     (บล็อกเพจ)   ← สัญญาณผี
```
สัญญาณผี: `depth 2+ / connection < 20%`, `messaging_block` สูง

### การตั้งค่าฝั่งแอด (ค่าที่ควรตั้ง)
- `publisher_platforms` = `facebook`, `instagram` (ตัด `audience_network`)
- `advantage_audience: 0` (ปิดขยายกลุ่ม — บาง campaign Meta บังคับเปิด ปิดได้แค่บางส่วน)
- Objective: เปลี่ยนจาก Messages → `LEAD_GENERATION` (Instant Form) / Call Ads
- Exclude custom audience = คนเคย message แต่ไม่ถึง depth 2

### ข้อควรระวังตอนทำจริง
- Lead Form: เพจต้องกด **Lead Ads Terms of Service** ก่อน (ครั้งเดียว/เพจ)
- Call Ads: `call_to_action: {type: CALL_NOW, value: {link: "tel:+66..."}}` (เบอร์แบบ E.164)
- ตำแหน่งโฆษณา: `video_feeds` เลิกใช้แล้ว → ใช้ feed/facebook_reels/story/instream_video
