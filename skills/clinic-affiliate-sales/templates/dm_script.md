# DM Script Templates — PARISMA Affiliate

---

## Stage 1: Cold Inquiry (ลูกค้าเพิ่งทัก)

```
สวัสดีค่ะ 🌸 ขอบคุณที่สนใจนะคะ
[ชื่อ] สนใจด้านไหนเป็นพิเศษคะ?
— ผิวหน้า (ขาว/ใส/กระชับ)
— โบท็อกซ์ / ฟิลเลอร์
— ยกกระชับ / ร้อยไหม
— วิตามินดริป
จะได้แนะนำให้ตรงจุดเลยค่ะ 😊
```

---

## Stage 2: Pain Discovery (ก่อน pitch — สำคัญมาก)

> ❗ ห้าม pitch หมอหรือบริการก่อนรู้ปัญหาลูกค้า

```
ขอบคุณค่ะ 😊
ตอนนี้อยากดูแลด้านไหนเป็นพิเศษคะ?
(เช่น ฝ้า / ริ้วรอย / หน้าหย่อนคล้อย / ผิวหมองคล้ำ / อยากปรับรูปหน้า / หรืออยากดูแลผิวให้ดีขึ้นทั่วไปก็ได้ค่ะ 🌸)
จะได้แนะนำให้ตรงจุดที่สุดเลยค่ะ
```

---

## Stage 3: Match Solution + Trust (หลังรู้ pain)

```
เข้าใจเลยค่ะ ปัญหาแบบนี้ [บริการ X] ตอบโจทย์ได้ดีมากค่ะ
ที่นี่หมอนุ้ยดูแลทุกเคสด้วยตนเองค่ะ
หมอเป็นสูตินรีแพทย์ดูแลด้านความงามโดยตรงค่ะ
[ชื่อ] เคยทำ [บริการ] มาก่อนไหมคะ?
```

---

## Stage 4: Price Question

```
ราคาขึ้นอยู่กับชนิดที่หมอแนะนำให้เหมาะกับคุณค่ะ
โดยประมาณอยู่ที่ [ช่วงราคา] ค่ะ
แต่ถ้าอยากได้ราคาแน่นอน แนะนำให้หมอประเมินให้ก่อนนะคะ
ฟรี ไม่มีค่าใช้จ่ายค่ะ 🌸
สะดวกวันไหนคะ?
```

---

## Stage 5: Close / Book (Active Close)

```
ยอดเยี่ยมเลยค่ะ 🌸
ยืนยันนะคะ:
📅 [วันที่]
⏰ [เวลา]
📍 PARISMA CLINIC ชลบุรี

เมื่อไปถึง แจ้งชื่อและบอก "จองผ่าน [ชื่อเพจ/LINE OA]" ด้วยนะคะ

ยืนยันวันที่ [X] เวลา [Y] ได้เลยไหมคะ? 😊
```

---

## Stage 6: Upsell (ส่งแยก — หลัง confirm ไปแล้ว 30–60 นาที)

> ❗ ห้ามส่งพร้อม Stage 5 — ลูกค้าจะรู้สึกถูก push

```
สวัสดีอีกครั้งค่ะ 🌸
อยากแนะนำอีกนิดนึงนะคะ
ขณะที่มาคลินิก มี [IV Drip / Eye Spa / Meso] ที่เหมาะกับ [pain ที่บอก] ด้วยค่ะ
ไม่ต้องตัดสินใจตอนนี้ก็ได้นะคะ ให้หมอดูให้อีกทีตอนมาถึงก็ได้ค่ะ 😊
```

---

## Stage 7: Follow-Up (ลูกค้าไม่ตอบ 48 ชม.)

```
สวัสดีค่ะ [ชื่อ] 🌸
ไม่ทราบว่ายังสนใจ [บริการ] อยู่ไหมคะ?
มีคำถามอะไรให้ช่วยตอบได้เลยนะคะ ไม่มีข้อผูกมัดค่ะ 😊
```

> ถ้าไม่ตอบอีก 48 ชม. → ส่ง follow-up สุดท้าย 1 ครั้ง แล้วหยุด ห้ามตามซ้ำ

```
[Follow-up สุดท้าย]
สวัสดีค่ะ 🌸 ฝากไว้นะคะ
ถ้าวันไหนสนใจกลับมาปรึกษาได้เสมอค่ะ
หมอนุ้ยยินดีต้อนรับเสมอนะคะ 😊
```

## Objection Scripts

### "แพงไปหน่อย"
```
เข้าใจเลยค่ะ 😊
บริการนี้หมอดูแลทุกขั้นตอนด้วยตนเองค่ะ
ถ้างบจำกัด มีตัวเลือกเริ่มต้นที่ [ราคาต่ำกว่า] ด้วยนะคะ
หรือให้หมอแนะนำตัวที่คุ้มค่าที่สุดสำหรับปัญหาของคุณก็ได้ค่ะ
```

### "ยังไม่แน่ใจ"
```
เข้าใจค่ะ 😊 ที่ยังไม่แน่ใจ เป็นเรื่องไหนคะ?
— ราคา (มีตัวเลือกหลายระดับค่ะ)
— ผลลัพธ์ (มีรีวิวจริงให้ดูได้ค่ะ)
— ความปลอดภัย (หมอเล่าให้ฟังได้ค่ะ)
— ยังไม่แน่ใจว่าบริการไหนเหมาะ (ปรึกษาหมอฟรีได้เลยค่ะ)
จะได้ตอบได้ตรงจุดค่ะ 🌸
```

### "เจ็บไหม"
```
หมอจะทาครีมชาก่อนทุกครั้งค่ะ 😊
ส่วนใหญ่ลูกค้าบอกว่าเจ็บน้อยมากค่ะ (ขึ้นอยู่กับแต่ละบุคคลนะคะ)
```

### "ปลอดภัยไหม"
```
หมอนุ้ยเป็นสูตินรีแพทย์ดูแลทุกเคสด้วยตนเองค่ะ
ทำภายใต้การดูแลของแพทย์โดยตรงนะคะ ปลอดภัยค่ะ 🌸
```

### "ไม่สนใจแล้ว"
```
ไม่เป็นไรเลยค่ะ 😊
ถ้าวันไหนเปลี่ยนใจหรืออยากปรึกษากลับมาได้เสมอนะคะ
ขอบคุณที่ให้เวลาค่ะ 🌸
```
