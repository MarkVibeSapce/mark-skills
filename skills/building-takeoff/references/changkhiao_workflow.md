# ช่างเขียว Workflow — ถอดแบบ → BOQ → เสนอราคา (bid package)

อ้างอิงจากงานจริง: Panelesmatic Solutions PCL Factory (ฐานราก/ตอม่อ/คาน/พื้น, คลองหลวง ปทุมธานี).
งานช่างเขียว = **ประมูลงานโครงสร้าง** ไม่ใช่แค่วัดของ. ถอดแบบเป็นแค่ขั้นกลาง.

## โครงเอกสาร 1 ชุดประมูล

```
แบบ (Drawings) ──┐
Spec (รายการประกอบแบบ) ─┼─→ ถอดปริมาณ ─→ BOQ (QT/ST/Prelim) ─→ เสนอราคา
ชี้แจงแบบ (เงื่อนไข) ──┘                                         + Bid Bond
```

## 1. แบบ → ปริมาณ
ดึง: จำนวนเข็ม, ปริมาณดินขุด/ถม, พื้นที่บดอัด, ปริมาตรคอนกรีตต่อหมวด, พื้นที่ไม้แบบ.
น้ำหนักเหล็กถอดจาก bar schedule ถ้ามี; ไม่มี → ratio (takeoff_method.md) + แตกขนาดด้วยสัดส่วน (contractor_boq_schema.md).

## 2. Spec (รายการประกอบแบบ) → วิธีวัด + เกรดวัสดุ
สารบัญ ST-Spec map ตรงกับหมวด BOQ:

| Spec section | กำกับรายการ BOQ |
|--------------|------------------|
| 1.4 งานถมดิน และปรับปรุงบริเวณ | ดินขุด / ดินถม / ทรายบดอัด (ทดสอบความแน่น 1 จุด/800 ตร.ม. AASHTO T-147) |
| 1.5 งานถนน ค.ส.ล. | งานถนน (ถ้ามีใน scope) |
| 1.6 งานแบบหล่อคอนกรีต | ไม้แบบ + ตะปู |
| 1.7 งานเหล็กเสริมคอนกรีต | เหล็ก RB (SR24) / DB (SD40) + ลวดผูกเหล็ก |
| 1.8 งานคอนกรีต | คอนกรีต 240 Ksc Cylinder (+ ผสมกันซึม) |
| 1.9 งานเหล็กรูปพรรณ | เหล็กรูปพรรณ (โครงหลังคา/structural steel) |
| 1.10 งานป้องกันความชื้น | กันซึม / membrane |

→ เปิด spec เพื่อยืนยัน **เกรด** (240/280/350 Ksc, SR24/SD40) ก่อนตั้งรายการ. อย่าเดา.

## 3. ชี้แจงแบบ → Prelim + เงื่อนไขราคา
รายการที่ต้องลงราคา/รับทราบ (จาก bid clarification):

**เงื่อนไขการเงิน-สัญญา:**
- Bid Bond (เช่น 10,000 บาท, 30 วัน)
- Advance Payment 5% + หักคืนรายงวด
- Performance Bond 5% (รวม VAT)
- **Retention 5% — ประกันผลงาน 730 วัน** หลังส่งมอบ
- Payment claim ตามผลงานรายเดือน จ่ายใน 30 วัน
- Insurance: CAR + บุคคลที่ 3 (คุ้ม Existing Property)
- Liquidated Damage: 0.1%/วัน ของ Contract Sum + ค่าควบคุมงาน 10,000/วัน
- Variation: Unit Cost จาก Final Negotiated BOQ — **ไม่คิด OH&P + ค่าเตรียมการ**
- Duration: ระบุชัด (เช่น 90 วัน)

**ผู้ควบคุมงานตามกฎหมาย (ต้องมีในต้นทุน):**
วิศวกรโยธาชั้นสามัญ + วิศวกรเครื่องกลชั้นสามัญ + สถาปนิกชั้นสามัญ ลงนามควบคุม.

**Checkpoint กันเงิน** (เช่น): จุด1 (2 ด.) ฐานราก+ตอม่อ 100%; จุด2 (3 ด.) คาน+พื้น 100% — กันเงิน 5,000/วัน ต่อจุด.

→ Prelim 28 รายการ (ดู contractor_boq_schema.md) map ตรงเงื่อนไขพวกนี้:
บอนด์→หลักประกัน, insurance→ประกันภัย CAR, ผู้ควบคุม→จป.+บุคลากรหลัก, ทดสอบวัสดุ, ทำความสะอาด-ล้างล้อ, Shop/As-Built Drawing.

## 4. Scope งานโครงสร้าง (5 ข้อมาตรฐานโรงงาน)
1. งานโครงสร้างฐานราก
2. งานโครงสร้างเสาตอม่อ
3. งานโครงสร้างคาน
4. งานโครงสร้างพื้น
5. **งานระบบท่อ Utility Piping ใต้อาคาร** ← อย่าตก

## เช็คลิสต์ก่อนส่ง BOQ ประมูล
- [ ] ทุกหมวด scope ครบ (รวม utility piping)
- [ ] เกรดวัสดุตรง spec (ไม่เดา)
- [ ] เหล็กแยกขนาด + ลวด + ตะปู ครบทุกหมวด
- [ ] Prelim ครอบเงื่อนไขชี้แจงแบบ (bond/retention/insurance/ผู้ควบคุม/duration)
- [ ] OH&P + VAT + ช่อง discount
- [ ] ASSUMPTIONS list (จุดที่ไม่มีแบบ ว./spec)
- [ ] เก็บ Unit Cost ครบ (ใช้คิด Variation ภายหลัง)
