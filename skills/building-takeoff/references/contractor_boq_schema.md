# Contractor BOQ (ช่างเขียว format) — schema + taxonomy

ใช้กับ `scripts/boq_contractor.py`. ออกไฟล์ 3 ชีต QT / ST / Prelim เชื่อมสูตร.

## JSON schema

```json
{
  "project": "NAWAMIN 107 RESIDENCE",
  "owner": "คุณอิทธิศักดิ์ อรรถพร",
  "job_no": "2026-xxx",
  "oh_profit_pct": 10,
  "vat_pct": 7,
  "structure": [
    {
      "code": "A1",
      "title": "งานโครงสร้างฐานราก",
      "items": [
        {"desc":"งานสกัดหัวเสาเข็ม","qty":20,"unit":"ต้น","mat_rate":0,"lab_rate":0,"assumption":true,"note":"ตามแบบ ว."}
      ]
    }
  ],
  "prelim": [
    {"desc":"ค่าสำรวจ วางผัง และจัดเตรียมพื้นที่ก่อสร้าง","unit":"Lot"}
  ]
}
```

- `mat_rate`/`lab_rate` = 0 → เว้นช่องราคาให้กรอกเอง. กรอกแล้ว amount/summary/OH&P/VAT/grand total คำนวณเองทั้งหมด.
- `waste_pct` (optional) → ปริมาณที่ลงราคา = สุทธิ × (1 + waste%). ช่อง `จำนวน` ถือเป็น **ปริมาณรวมเผื่อ** (gross), หมายเหตุโชว์ "สุทธิ X +เผื่อ Y%". ดูค่าเริ่ม "Wastage" ข้างล่าง.
- `assumption: true` → แถวขึ้นแดง + เครื่องหมาย ⚠ ในหมายเหตุ.
- qty/rate ที่ไม่ใช่ตัวเลข → generator แปลงเป็น 0 + พิมพ์คำเตือน (กัน formula พัง).
- OH&P% / VAT% อยู่ในเซลล์ (คอลัมน์ E แถวนั้น) แก้ % แล้วยอดคำนวณใหม่อัตโนมัติ.
- โครงสร้าง section roll-up: detail TOTAL → ST summary → QT.

## Taxonomy มาตรฐาน (วนต่อทุกหมวด ฐานราก/ตอม่อ/พื้น/คาน)

เรียงลำดับนี้เสมอ (ข้ามรายการที่ไม่มีได้):
1. งานเสาเข็ม — **แยกชนิด**:
   - เข็มตอก/precast → งานสกัดหัวเสาเข็ม (ต้น) [supply เข็มแยกถ้าผู้รับเหมาจัดหา]
   - เข็มเจาะ/bored → งานคอนกรีตเสาเข็มเจาะ (ลบ.ม.) + เหล็ก (กก.) + ดินเจาะ
2. งานดินขุด — ลบ.ม.
3. งานดินถม / งานดินถมใต้อาคาร — ลบ.ม.
4. งานทรายหยาบบดอัดแน่น — ลบ.ม.
5. แผ่นพลาสติกปูพื้น หนา 0.07 มม. — ตร.ม.
6. งานคอนกรีตหยาบ — ลบ.ม.  (**ไม่มีเหล็ก** — อย่าคิด rebar จากปริมาตรนี้)
7. งานคอนกรีตโครงสร้าง 240 Ksc Cylinder — ลบ.ม.
8. งานคอนกรีตโครงสร้าง 240 Ksc Cylinder (ผสมกันซึม) — ลบ.ม. (เฉพาะพื้น/หลังคา/ห้องน้ำ)
9. **งานเหล็กแยกขนาด** (กก.):
   - RB6 / RB9 / RB12 มม. SR 24 มอก. (เหล็กกลม — ปลอก/เสริม)
   - DB12 / DB16 / DB20 / DB25 มม. SD 40 มอก. (เหล็กข้ออ้อย — เหล็กหลัก)
10. งานไม้แบบ — ตร.ม.
11. งานตะปู — กก.
12. งานลวดผูกเหล็ก — กก.

รายการเพิ่มตามสภาพหน้างาน/spec (อย่าตก):
- งานสูบน้ำหลุม (Dewatering) — Lot/วัน  (spec 1.4.3 ขุดฐานราก)
- งานค้ำยันผนังกันดิน (Shoring/Sheet pile) — ตร.ม./Lot  (ขุดลึก)
- งานทดสอบเสาเข็ม (Pile load test: static/dynamic/seismic) — ต้น/จุด
- งานทดสอบคอนกรีต (cylinder test 240 Ksc) — ชุด
- งานทดสอบความแน่นดิน (compaction) — จุด (1 จุด/800 ตร.ม. ตาม spec 1.4)
- งานระบบท่อ Utility Piping ใต้อาคาร — ม./Lot  (scope ข้อ 5)

## Ratio แปลงปริมาณ (เมื่อไม่มี bar schedule — ติด ASSUMPTION)

**คอนกรีต→เหล็ก**: ปริมาตร คสล. (เฉพาะคอนกรีตโครงสร้าง ไม่รวม lean) × ratio กก./ลบ.ม. (ดู takeoff_method.md).
ratio = น้ำหนักเหล็กตาม bar schedule (theoretical). **ยังไม่รวมทาบต่อ (lap) + เศษตัด** → ต้องใส่ `waste_pct` เหล็ก (ดูล่าง).

**แยกตามขนาด — ใช้ distribution ตามชนิดชิ้นส่วน (ไม่ใช่ % เดียวทั้งงาน):**
| ชิ้นส่วน | RB6 | RB9 | DB12 | DB16 | DB20 | DB25 |
|---------|-----|-----|------|------|------|------|
| ฐานราก (footing) | – | 10% | 20% | 35% | 25% | 10% |
| เสาตอม่อ/เสา (column) | 8% | 17% | 30% | 30% | 10% | 5% |
| คาน (beam) | 5% | 15% | 35% | 30% | 12% | 3% |
| พื้น (slab) | 5% | 35% | 50% | 10% | – | – |
> RB = ปลอก/เหล็กกลม (SR24), DB = เหล็กหลักข้ออ้อย (SD40). ตึกสูง: เสาชั้นล่างเลื่อนไป DB25 มากขึ้น.

**รายการแฝง:**
- **ตะปู** ≈ 0.25 กก. ต่อ ไม้แบบ 1 ตร.ม.  (calibrate จาก template)
- **ลวดผูกเหล็ก** ≈ 2% ของน้ำหนักเหล็กรวม — หน่วย **กก.** (template ต้นฉบับพิมพ์ "ตร.ม." = typo อย่าลอก)
- **ไม้แบบ** = พื้นที่หน้าสัมผัส (คาน+เสา+ท้องพื้น+ขอบ)
- **คอนกรีตหยาบ** = พื้นที่ฐาน/พื้น × 0.05
- **ทรายรองพื้น** = พื้นที่ × 0.05

## Wastage / เผื่อเสียหาย (ใส่ `waste_pct` — สำคัญ: NET ล้วนซื้อของไม่พอ)
| วัสดุ | waste_pct เริ่มต้น | หมายเหตุ |
|------|-------------------|---------|
| คอนกรีต (โครงสร้าง/หยาบ) | 3% | หกหล่น+ค้างปั๊ม |
| เหล็กเสริม | 8% | ทาบต่อ lap ~5% + เศษตัด ~3% |
| ไม้แบบ | 5% | แตกหัก (reuse คิดใน rate) |
| ทราย/ดินถม | 5% | bulking/สูญเสีย |
| แผ่นพลาสติก | 10% | ทาบขอบ overlap |
> ถ้าถอดจาก bar schedule จริง (รวม lap แล้ว) → ใช้เหล็ก waste แค่ 3% (เศษตัดอย่างเดียว).

## QT สรุป
A Structure (=ST) + B Prelim → TOTAL COST → OVERHEAD&PROFIT (default 10%) →
TOTAL → SPECIAL DISCOUNT → TOTAL(EXCLUDE VAT) → VAT (default 7%) → GRAND TOTAL.
