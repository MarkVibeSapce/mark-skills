# มาตรฐาน BOQ ที่ไทยยอมรับ — เปรียบเทียบ + แบบฟอร์ม

ไทยมี 3 สายหลัก: **ราชการ (ปร.4/5/6 + Factor F)**, **เอกชน/ผู้รับเหมา (BOQ + OH&P)**, **สากล (SMM/NRM)**. เลือกตามผู้ว่าจ้าง.

## เปรียบเทียบภาพรวม

| มาตรฐาน | ใช้กับ | แบบฟอร์ม | บวกกำไร/ค่าใช้จ่าย | วิธีวัดปริมาณ |
|---------|--------|----------|---------------------|---------------|
| **ราชการ — กรมบัญชีกลาง** | งานภาครัฐ (บังคับ) | **ปร.4 → ปร.5 → ปร.6** | **Factor F** (ตารางสำเร็จ รวม overhead+ดอกเบี้ย+กำไร+ภาษี ในตัวเดียว) | หลักเกณฑ์คำนวณราคากลางฯ (อาคาร/ทาง/ชลประทาน) |
| **เอกชน / ผู้รับเหมา** | งานเอกชน, ประมูลเอกชน | อิสระ — QT/BOQ + Prelim (แบบช่างเขียว) | **OH&P % แยก** (10-15%) + VAT 7% แยก | ตามผู้รับเหมา / อิง SMM |
| **สากล — SMM / NRM (RICS)** | โครงการใหญ่/ต่างชาติ/QS วิชาชีพ | BOQ ตาม SMM + Preliminaries แยกเล่ม | Preliminaries + OH&P | SMM7 / NRM2 (rules วัดละเอียด) |

หมายเหตุลำดับความสำคัญเอกสาร (ราชการ): **รูปแบบรายการ > รายการประกอบแบบ (spec) > BOQ** — ขัดแย้งกันให้ยึดแบบรูปก่อน.

---

## 1. ราชการ — ปร.4 / ปร.5 / ปร.6 (กรมบัญชีกลาง)

ลำดับ: **ถอดแบบ → ปร.4 (ต้นทุนตรง) → ปร.5 (× Factor F = ราคากลาง) → ปร.6 (สรุปรวม)**

### ปร.4 — แบบแสดงรายการปริมาณงานและราคา (ต้นทุนตรง direct cost)
ถอดแบบรายหมวด, หลายแผ่น. **ยังไม่รวม Factor F.**
```
หัว: ชื่อโครงการ | สถานที่ | แบบเลขที่ | ปร.4 แผ่นที่ x/y
| ลำดับ | รายการ | จำนวน | หน่วย | ค่าวัสดุ(ราคา/หน่วย | จำนวนเงิน) | ค่าแรงงาน(ราคา/หน่วย | จำนวนเงิน) | รวมค่าวัสดุ+ค่าแรง | หมายเหตุ |
ท้าย: รวมค่างานต้นทุน (หมวดนี้)
```
> = หน้าตาเดียวกับชีต ST ของเรา (แยกวัสดุ/ค่าแรง). ต่างที่ ปร.4 ไม่บวก markup ในแผ่นนี้.

### ปร.5(ก) — แบบสรุปราคากลาง (คูณ Factor F)
```
| ลำดับ | รายการ (หมวดงาน: โครงสร้าง/สถาปัตย์/ระบบ) | ค่างาน(จาก ปร.4) | Factor F | รวมค่างาน(=ค่างาน×F) | หมายเหตุ |
ท้าย: ราคากลางรวม + ระบุค่า Factor F ที่ใช้ + เงื่อนไข
```
- **ปร.5(ก)** = งานก่อสร้างทั่วไป (คูณ F).
- **ปร.5(ข)** = ค่าครุภัณฑ์จัดซื้อ/งานที่ไม่คูณ F (บวกเฉพาะกำไร/ภาษีบางส่วน).

### ปร.6 — แบบสรุปราคากลางงานก่อสร้าง (สรุปรวมโครงการ)
```
รวมราคากลางทุกหมวด (จาก ปร.5) → ราคากลางงานก่อสร้างรวม → ปัดเศษ
+ ชื่อ-ลายเซ็น คณะกรรมการกำหนดราคากลาง (≥3 คน) + วันที่ + แหล่งราคาอ้างอิง (สนค./พาณิชย์)
```

### Factor F (ตัวคูณราคากลาง) — หัวใจฝั่งราชการ
- **ราคากลาง = ค่างานต้นทุน (ปร.4) × Factor F**
- F รวมในตัวเดียว: **ค่าอำนวยการ (overhead) + ดอกเบี้ยเงินกู้ + กำไร + ภาษี (VAT)**
- เป็น **ตารางสำเร็จรูปกรมบัญชีกลาง** เลือกตาม: ประเภทงาน (อาคาร / ทาง-สะพาน / ชลประทาน) × **ช่วงวงเงินค่างานต้นทุน** × เงื่อนไขเงินล่วงหน้า/จ่ายเงิน.
- **ยิ่งวงเงินใหญ่ F ยิ่งต่ำ** (economy of scale). งานอาคารทั่วไป F ประมาณ ~1.2–1.3 (ใช้ค่าจริงจากตารางเท่านั้น ห้ามเดา).
- อัปเดตล่าสุดอ้างอิง: **ว 499 ลว. 28 ส.ค. 2566 — Factor F อัตราดอกเบี้ยเงินกู้ 7%**.

## 2. เอกชน / ผู้รับเหมา (แบบช่างเขียว = ที่ skill นี้ทำ)
ไม่มีฟอร์มบังคับ. นิยม:
```
BOQ รายหมวด → รายการ → qty × (ค่าวัสดุ + ค่าแรง) = Direct Cost
→ OVERHEAD & PROFIT % (10–15% แยกชัด)
→ SPECIAL DISCOUNT
→ VAT 7%
→ GRAND TOTAL
+ Preliminaries (งานทั่วไป) แยกหมวด
```
ต่างจากราชการ: **แยก OH&P + VAT ออกมาเห็นชัด** (ไม่ฝังใน F) → ต่อรอง + คิด Variation ง่าย (Variation ใช้ unit cost ไม่คิด OH&P).

---

## 3. สากล — SMM / NRM (RICS)
- **SMM** = Standard Method of Measurement (วิธีวัดปริมาณงานมาตรฐาน). **NRM2** = New Rules of Measurement (เวอร์ชันใหม่ RICS).
- BOQ แยก: Preliminaries / Measured Works / Provisional Sums / Dayworks.
- ใช้กับโครงการใหญ่, นายทุนต่างชาติ, งานที่มี QS วิชาชีพ (MRICS). ปริมาณวัดตาม rule ละเอียด (เช่น หักช่องเปิด > ขนาดกำหนด).
