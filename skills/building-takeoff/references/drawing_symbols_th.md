# อ่านแบบก่อสร้าง — สัญลักษณ์ + notation (ไทย) สำหรับถอดแบบ

จุดมุ่ง: อ่าน plan/section/schedule แล้ว **ดึงปริมาณได้ถูก**. ทุก notation จบที่ "แปลงเป็น qty อย่างไร".
> สำคัญ: แต่ละสำนักออกแบบใช้ตัวย่อต่างกัน — **อ่านหน้า General Notes / สารบัญสัญลักษณ์ ของชุดแบบก่อนเสมอ**.

## 1. รหัสชุดแบบ (sheet codes)
| รหัส | หมวด |
|------|------|
| A / AR | สถาปัตย์ (Architecture) — plan, elevation, section |
| S / ST | โครงสร้าง (Structural) — foundation, column/beam/slab schedule |
| SN / SAN | สุขาภิบาล (Sanitary) |
| E / EE | ไฟฟ้า (Electrical) |
| M | เครื่องกล/ปรับอากาศ (Mechanical) |
เลขชีต เช่น A-3000 = ผังพื้น, A-4000 = รูปด้าน, A-4101 = section, S-2xxx = ฐานราก.

## 2. Grid + ระดับ + มาร์ก
- **Grid line**: ตัวเลข (1,2,3..) แกนนอน × ตัวอักษร (A,B,C..) แกนตั้ง. วงกลม=grid bubble. ระยะระหว่าง grid = span → ใช้คิดความยาวคาน/พื้นที่.
- **ระดับ EL.** = Elevation/ระดับความสูง. `EL.+0.80` = สูงจากอ้างอิง 0.80 ม. `±0.00` = ระดับอ้างอิง (มักเป็น FFL ชั้น 1).
  - **FFL** = Finish Floor Level (ผิวพื้นเสร็จ) · **SSL** = Structural Slab Level (หลังพื้นโครงสร้าง) · **TOC/TOS** = Top of Concrete/Slab · **TOF** = Top of Footing · **GL** = Ground Level (ดินเดิม).
  - ผลต่างระดับ = ความลึก/ความสูง → คิดดินถม/ขุด, ความสูงเสา/ผนัง.
- **Section mark** ▭→ (เส้นตัด + ลูกศรทิศมอง + เลข detail/sheet). **Detail bubble** ⊙ (วงกลมล้อมส่วนขยาย). **Elevation/view arrow**. **North arrow** = ทิศเหนือ.

## 3. รหัสชิ้นส่วนโครงสร้าง
| รหัส | คือ | ถอดเป็น |
|------|-----|---------|
| **F1, F2..** | ฐานราก (Footing) | คอนกรีต (กว้าง×ยาว×ลึก) + เหล็ก |
| **PILE / เข็ม** | เสาเข็ม | ต้น (precast) / ลบ.ม.+เหล็ก (เจาะ) |
| **ตอม่อ / SC** | เสาตอม่อ (stub column ใต้ดินถึงคานคอดิน) | คอนกรีต + เหล็ก |
| **C1, C2..** | เสา (Column) | หน้าตัด × สูง × จำนวน |
| **B1, GB, คาน, คานคอดิน** | คาน (Beam) / Ground Beam | b×h×ความยาว span |
| **S1, พื้น / Slab** | พื้น | พื้นที่ × ความหนา |
| **W / SW** | ผนังรับแรง (Wall / Shear Wall) | พื้นที่ × ความหนา |
หมายเหตุ: บ้านไทยลำดับ ฐานราก F → เข็ม → ตอม่อ → คานคอดิน → เสา C → คานรับพื้น/หลังคา B → พื้น S.

## 4. เหล็กเสริม (rebar callout) — หัวใจของถอดเหล็ก
- **RB** = Round Bar = เหล็กเส้นกลม **SR24** (ใช้เป็นปลอก/เหล็กเสริมเล็ก). **DB** = Deformed Bar = เหล็กข้ออ้อย **SD40** (เหล็กหลัก).
- เลขหลังตัวอักษร = เส้นผ่านศูนย์กลาง มม. เช่น DB16 = ข้ออ้อย 16มม., RB9 = กลม 9มม.
- **@ = ระยะเรียง (spacing)**: `DB12@200` = เหล็ก DB12 ทุกระยะ 200มม. · `ปลอก RB6@150` = ปลอกเหล็กกลม 6มม. ทุก 150มม.
- **จำนวน-ขนาด**: `4-DB16` = เหล็กหลัก 4 เส้น DB16. `2-DB12 บน + 3-DB12 ล่าง` = คาน เหล็กบน 2 ล่าง 3.
- ตัวย่อตำแหน่ง: **T** = Top (บน) · **B** = Bottom (ล่าง) · **EF** = Each Face (สองหน้า) · **EW** = Each Way (สองทาง) · **O.C.** = On Center · **Extra/Extra Top** = เหล็กเสริมพิเศษช่วง support.
- **น้ำหนัก** = (D²/162) กก./ม. × ความยาว × จำนวน. (D หน่วย มม.) — ดู price_db steel_unit_weight.
- **lap (ทาบต่อ)** มาตรฐาน ~40D (เหล็กข้ออ้อย) → เพิ่มน้ำหนัก ใส่ waste. **cover (ระยะหุ้ม)** ฐานราก 7ซม. เสา/คาน 2.5-4ซม. **hook/งอ** ปลายปลอก 135°.

## 5. คอนกรีต
- **240 ksc** = กำลังอัด 240 กก./ตร.ซม. (Ksc = kg/cm²). ระบุ Cylinder (ทรงกระบอก) หรือ Cube (ลูกบาศก์). **fc'** = กำลังอัดออกแบบ.
- เกรดทั่วไป: 180 (lean/หยาบ), 210, 240 (โครงสร้างบ้าน), 280-350 (อาคารใหญ่/เสาตึกสูง).
- "คอนกรีตหยาบ / lean" = รองใต้ฐานราก ไม่มีเหล็ก.

## 6. ลายเส้น hatching (รูปตัด/section)
| ลาย | วัสดุ |
|-----|-------|
| จุดเล็ก + สามเหลี่ยม | คอนกรีต คสล. |
| จุดถี่ | ทราย |
| เส้นเฉียงสลับ/ก้อน | ดินถม |
| อิฐเรียง | ผนังก่ออิฐ |
| ทึบ/เส้นทแยง | เหล็ก/โลหะ |
| ลายไม้ | ไม้ |

## 7. ประตู-หน้าต่าง
- **D1, D2..** = Door (ประตู) · **W1, W2..** = Window (หน้าต่าง). นับจาก **Door/Window Schedule** (ตารางบอกขนาด+ชนิด+จำนวน). อย่านับจาก plan อย่างเดียว — เทียบ schedule.

## 8. อ่าน Schedule → ถอดปริมาณ (วิธีที่แม่นสุด)
ถ้าแบบมี schedule ใช้ก่อน ratio เสมอ:
- **Footing schedule**: F1 = ขนาด BxLxT + จำนวนเข็ม + เหล็ก (เช่น DB16@150 EW) → คอนกรีต=B×L×T×จำนวนฐาน; เหล็ก=นับเส้น×ยาว×น้ำหนัก.
- **Column schedule**: C1 = หน้าตัด + เหล็กหลัก (8-DB16) + ปลอก (RB9@200) → คอนกรีต=หน้าตัด×สูง; เหล็กหลัก=8×สูง(+lap)×wt; ปลอก=(สูง/0.20)×ความยาวรอบ×wt.
- **Beam schedule**: B1 = bxh + เหล็กบน/ล่าง + ปลอก → คอนกรีต=b×h×L; เหล็ก=ผลรวมเส้น×L + ปลอก.
- **Slab**: S1 = ความหนา + เหล็กบน-ล่าง (ทางเดียว/สองทาง) → คอนกรีต=พื้นที่×t; เหล็ก=ตาม @spacing สองทิศ.

## 9. ตัวย่อไทยที่เจอบ่อย
คสล./ค.ส.ล. = คอนกรีตเสริมเหล็ก · ผกง./ก่อ = ผนังก่อ · ปรับ = ปรับระดับ · @ = ระยะเรียง · ø/Ø = เส้นผ่านศูนย์กลาง · ทกพ. = ตามแบบ · SLOPE/ลาด = ความลาดเอียง · ระยะร่น = setback · NTS = Not To Scale · TYP. = Typical (เหมือนกันทุกจุด) · CL = Center Line.

## 10. เช็คก่อนเชื่อตัวเลข
- มิติ dimension string บางทีซ้อน note — cross-check กับผลรวม grid span.
- มี schedule → ใช้ schedule. ไม่มี → ratio (takeoff_method.md) + ASSUMPTION.
- เกรดคอนกรีต/เหล็ก ยืนยันจาก **General Notes / spec** ไม่ใช่เดา.
