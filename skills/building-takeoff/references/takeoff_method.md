# Takeoff Method — สูตร + ratio ต่อหมวด

ระดับความละเอียด = **ประมาณการ (estimate)**. ถ้ามี structural/MEP drawing จริง ให้ override ทุก ratio ด้วยตัวเลขจากแบบ.

## A. งานเตรียม + ฐานราก (Substructure)

| รายการ | สูตร / basis | หน่วย |
|--------|--------------|-------|
| ปรับพื้นที่/ขุดดิน | footprint × ความลึกเฉลี่ย (จาก section EL.) | ลบ.ม. |
| เสาเข็ม | จำนวนต้น × ความยาว (จาก foundation plan) | ต้น / ม. |
| ฐานราก (footing) | Σ (กว้าง×ยาว×ลึก) ต่อ F1,F2,... | ลบ.ม. |
| คอนกรีตหยาบ (lean) | พื้นที่ footing × 0.05–0.10 | ลบ.ม. |

ไม่มี foundation plan → ASSUMPTION: บ้าน/เตี้ย ใช้ฐานรากแผ่/เข็มสั้น; อาคารสูง = เสาเข็มเจาะ ต้องมีแบบ ว. เท่านั้น (อย่าเดาจำนวน).

## B. โครงสร้าง (Superstructure)

- **เสา (column):** Σ (พื้นที่หน้าตัด × ความสูงชั้น × จำนวนเสา) = ลบ.ม. คอนกรีต.
- **คาน (beam):** Σ (ความยาวคาน × หน้าตัด). ความยาวคาน ≈ ผลรวม grid span ในชั้น.
- **พื้น (slab):** พื้นที่พื้นแต่ละชั้น × ความหนา. RC slab ทั่วไป 0.12–0.15 ม.; post-tension 0.20–0.28 ม.
- **บันได/core:** ถอดต่อชั้น × จำนวนชั้น.

### Rebar ratio (เมื่อไม่มีแบบ ว. — ติด ASSUMPTION ตัวหนา)

ปริมาณเหล็ก = ปริมาตรคอนกรีต (ลบ.ม.) × ratio (กก./ลบ.ม.):

| ส่วน | กก./ลบ.ม. คอนกรีต |
|------|-------------------|
| ฐานราก | 80–120 |
| เสา (ชั้นล่างตึกสูง) | 180–250 |
| เสา (ชั้นบน/บ้าน) | 100–150 |
| คาน | 120–180 |
| พื้น RC | 80–110 |
| พื้น post-tension | 30–50 (เหล็ก) + ลวดอัดแรง |

ตึกสูง: ชั้นล่าง ratio + หน้าตัดเสาใหญ่กว่า ชั้นบน. แบ่งเป็น 3 โซน (ล่าง/กลาง/บน) ถ้าไม่มีแบบละเอียด.

### High-rise structural shortcut
```
คอนกรีตโครงสร้างรวม ≈ พื้นที่ก่อสร้างรวม (ตร.ม.) × ดัชนี (ลบ.ม./ตร.ม.)
  - บ้าน/อาคารเตี้ย RC:        0.30–0.40
  - อาคารสูง RC (10–40 ช.):    0.40–0.55
  - อาคารสูงมาก (>40 ช.):      0.50–0.65
```
ใช้เป็น sanity-check กับผลถอดแบบ detail. ต่างกันเกิน ±20% → ทบทวน.

## C. งานสถาปัตย์ (Architecture)

| รายการ | สูตร | หน่วย |
|--------|------|-------|
| ผนัง (ก่อ) | (เส้นรอบรูป + ผนังภายใน) × ความสูงชั้น − ช่องเปิด | ตร.ม. |
| ฉาบปูน | พื้นที่ผนัง × 2 หน้า (ภายใน+ภายนอก ตามจริง) | ตร.ม. |
| พื้นผิว (กระเบื้อง/ไม้/หินขัด) | พื้นที่พื้นแต่ละห้องตาม finish schedule | ตร.ม. |
| ฝ้าเพดาน | พื้นที่ฝ้าตาม ceiling plan (แยกชนิด C1/C2) | ตร.ม. |
| หลังคา | พื้นที่ลาดเอียง = พื้นที่ราบ ÷ cos(มุม). metal sheet, CPAC, ฯลฯ | ตร.ม. |
| ประตู/หน้าต่าง | นับจาก door/window schedule (D1,W1,...) | ชุด |
| สี | = พื้นที่ฉาบ (ผนัง) + ฝ้า | ตร.ม. |

ช่องเปิด: หักพื้นที่ประตู+หน้าต่างออกจากผนัง. หลังคาเอียง: คูณ factor 1/cos — ลาด 25° → ÷0.906 ≈ ×1.10; metal sheet ลาดน้อย ×1.02–1.05.

## D. งานระบบ MEP (allowance)

ไม่มีแบบระบบ → ประมาณเป็น % ของค่าก่อสร้างหรือต่อ ตร.ม.:

| ระบบ | allowance |
|------|-----------|
| ไฟฟ้า+สื่อสาร | 8–12% ของค่าก่อสร้าง |
| สุขาภิบาล/ประปา | 5–8% |
| ปรับอากาศ | 6–10% (บ้านคิดต่อชุด BTU) |
| ลิฟต์ (ตึกสูง) | ต่อตัว × จำนวน stop |
| ดับเพลิง (ตึกสูง บังคับ) | 4–7% |

ระบุชัดว่าเป็น "allowance %" ไม่ใช่ถอดจริง.

## JSON schema (input ของ boq_excel.py / boq_pdf.py)

```json
{
  "project": "NAWAMIN 107 RESIDENCE",
  "owner": "คุณอิทธิศักดิ์",
  "note": "ประมาณการเบื้องต้น — qty อย่างเดียว ยังไม่ใส่ราคา",
  "currency": "THB",
  "factor_label": "ค่าดำเนินการ + กำไร (F)",
  "items": [
    {
      "category": "B. งานโครงสร้าง",
      "desc": "คอนกรีตเสา (โครงสร้าง คสล.)",
      "qty": 12.5, "unit": "ลบ.ม.",
      "mat_rate": 0, "lab_rate": 0,
      "basis": "หน้าตัด 0.30×0.30 × สูง 3.6 × 32 เสา",
      "assumption": false
    }
  ]
}
```

- `mat_rate`/`lab_rate` = 0 → script เว้นช่องราคาให้กรอกเอง (โหมดปริมาณอย่างเดียว).
- `assumption: true` → แถวขึ้นเครื่องหมาย ⚠ + รวมไว้ใน sheet "ASSUMPTIONS".
- `category` ขึ้นต้น A./B./C./D. เพื่อ sort + subtotal อัตโนมัติ.
- `basis` = string อธิบายที่มาตัวเลข (โชว์เป็น note ใน Excel).
